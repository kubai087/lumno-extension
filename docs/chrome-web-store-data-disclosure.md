# Lumno Chrome Web Store 数据披露清单

更新日期：2026-10-02

这份清单用于填写 Chrome Web Store Dashboard。发布者需要按 Dashboard 当时显示的字段逐项核对；若实现、权限或政策文案变化，先更新披露，再上传新版。

## 单一用途

建议填写：

> Lumno 是一个本地优先的浏览器效率工具，提供命令栏、新标签页、搜索与标签页操作；默认使用 Chrome 浏览器内置同步。用户可选择连接自己的 WebDAV 服务器，同步完整配置、自定义快捷方式图标和上传的壁纸。

## 数据类型选择

| Dashboard 数据类型 | 选择 | 说明 |
| --- | --- | --- |
| Personally identifiable information / 个人身份信息 | 发布前重新核对 | 无 Lumno 独立账号；WebDAV 用户名可能包含邮箱，由用户输入并用于连接其指定服务器。 |
| Authentication information / 身份验证信息 | 发布前重新核对 | 可选 WebDAV 功能处理用户名和应用密码，凭据只保存在本机扩展源 IndexedDB，并通过 HTTPS 认证用户指定服务器；不进入 Chrome 同步或配置快照。 |
| Personal communications / 个人通信 | 否 | 不采集邮件、聊天或其他通信内容。 |
| Location / 位置信息 | 否 | 不采集精确或粗略位置。粗粒度平台类型不是位置。 |
| Web history / 浏览历史 | 否（不传输） | 核心功能可在本机读取浏览历史和当前上下文，但不会把它们发送到 Lumno 或开发者服务器。 |

## 数据使用认证

应确认：

- 不出售或转让用户数据，不用于个性化广告、信用评估或画像；
- 不向 Lumno 或开发者服务器上传浏览数据、网站内容和使用统计；WebDAV 仅在用户主动配置后，向其指定服务器传输配置与自定义媒体；
- 遵守 Chrome Web Store User Data Policy 的 Limited Use 要求。

## 数据保留与公开链接

- 获取第三方图标时，Gstatic 会接收目标页面 URL；用户主动选择 Favicon.is 时，仅向该服务发送目标主机名，获取域名图标。请求不携带 Cookie 或来源页 Referer，图片结果保存在本机；关闭增强获取后仍可请求白名单内的图标服务，但不直接加载目标网站图片；命中图标排除规则后，不请求这些服务。网页浮层通过扩展后台取得图片数据后展示，不直接连接第三方服务；
- 普通配置由 Chrome 浏览器内置同步保存，保留和删除遵循用户的 Chrome 账号及浏览器设置；
- 自定义壁纸、快捷方式图标及其他本机数据保存在浏览器扩展存储或 IndexedDB，可通过删除对应内容或卸载扩展移除；
- WebDAV 开启后，本机保留完整数据和替换前备份，服务器保存配置、图片及覆盖前快照；暂停、切回 Chrome 或卸载不会删除服务器文件，远端历史快照和孤立图片暂需用户在服务器端清理；
- WebDAV 不提供端到端加密，用户指定服务器的管理员可以读取配置和媒体。凭据只保存本机，其他设备需单独配置；
- Lumno 不维护账号数据库、云端媒体库或产品使用统计；
- 每日名句默认关闭；用户开启后，向一言（`v1.hitokoto.cn`）获取所选分类的公开语句，响应按天缓存在本机。请求不包含浏览记录、书签、搜索词或账号信息；
- 用户打开 Bing 来源或启用每日壁纸后，向 `www.bing.com` 获取首页壁纸信息和缩略图，选中的图片下载一次后压缩缓存在本机 IndexedDB，只保留当前使用的那张。请求只包含语言市场和图片标识，不携带 Cookie、来源页 Referer、浏览记录、书签或搜索词；第三方服务会收到正常网络请求的 IP 地址。每日模式或固定壁纸编号随配置同步，今日选图及图片缓存保存在本机扩展存储和 IndexedDB，不进入 Chrome Sync 或 WebDAV 媒体快照；
- 用户打开精选来源后，向 `picsum.photos`（Lorem Picsum，图片来自 Unsplash）获取缩略图，选中的图片下载一次后压缩缓存在本机 IndexedDB，只保留当前使用的那张。请求只包含图片编号和尺寸，不携带 Cookie、来源页 Referer、浏览记录、书签或搜索词；第三方服务会收到正常网络请求的 IP 地址。艺术分类向 `openaccess-cdn.clevelandart.org`（克利夫兰艺术博物馆开放获取，CC0）获取预览图，选中后下载一次原图，压缩后缓存在本机 IndexedDB，只保留当前使用的那张。图片清单、摄影师和作品署名随扩展打包，每日模式按本机日期从所选分类中选图，不额外请求；同步的只有图片编号或“每日 + 分类”；
- 用户在本地来源中粘贴单张图片的链接后，链接地址随配置同步（Chrome Sync 或 WebDAV）；每台设备向该链接发起一次不带 Cookie 和 Referer 的请求，把图片压缩后缓存在本机 IndexedDB，之后使用缓存。缓存的图片不进入 Chrome Sync 或 WebDAV 媒体快照；删除链接会从所有同步设备移除；

## 权限理由核对

Dashboard 中的每项权限理由应只描述实际需要：

- `storage`：保存本地设置，并通过 Chrome 浏览器内置同步同步普通配置；
- `unlimitedStorage`：保存 WebDAV 模式下的完整本机配置、自定义图片、同步缓存和恢复备份，避免沿用 Chrome Sync 的小容量作为本机上限；
- `alarms`：定期检查 WebDAV 远端配置，在服务工作线程停止后重新触发同步；
- 标签页、书签、历史等现有权限：仅支持用户主动触发的本地搜索或标签页操作，不把内容发送到 Lumno 或开发者服务器；
- `<all_urls>`：用于用户主动启用的页面快捷操作、画中画、站点图标能力、从用户粘贴的图片链接导入壁纸，以及后台访问用户配置的 HTTPS WebDAV 地址，不用于向开发者服务器收集浏览数据。

上传前核对源码、构建产物、Dashboard 数据类型和公开隐私政策，确保描述包含可选 WebDAV 的配置/媒体传输与本机凭据处理；确认不存在未披露的账号或遥测运行时。此清单记录实现行为，Dashboard 选项需发布者按当时要求确认。
