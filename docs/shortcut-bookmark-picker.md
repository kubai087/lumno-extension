# 从收藏夹添加快捷方式

适用版本：本 fork 的 1.0.3 及以上。

1. 点击新标签页的“添加快捷方式”按钮，在原有加号菜单中选择“添加网站”。
2. 在添加窗口点击“从收藏夹选择”。列表包含浏览器全部收藏夹根目录及其子文件夹中的可用网址。
3. 搜索名称、网址或文件夹路径，选中网站后自动填入名称和网址。也可以按 Enter 选择首个可添加的匹配项。
4. 按需要修改名称、网址或图标来源，然后点击“完成”。快捷方式加入原有的目标分组，继续使用已有的图标、排序和编辑功能。

此操作只读取原生收藏夹，创建独立的快捷方式；不会移动、修改或删除收藏夹中的网站。原收藏发生变化后，已经创建的快捷方式不会自动跟随修改。“自定义最常访问”保留，两种手动管理方式可同时使用，互不合并。

已经存在于快捷方式中的相同规范化网址会显示“已添加”，不能重复选择。列表不显示文件夹本身、不支持的网址协议或带用户名／密码的网址。空收藏夹和搜索无结果时仍可在下方手动填写网址；读取失败可点击“重试”。

每次展开读取现有收藏夹运行时缓存，收藏夹变更事件会使缓存失效。初始显示 30 个搜索结果，点击“显示更多”每次增加 30 项；搜索覆盖全部候选，不限于已显示的结果。关闭窗口或选择区后，迟到的读取结果不会重新打开界面；旧请求不能覆盖新请求。

展开后焦点进入搜索框；加载或失败时 Enter 不选择结果。搜索框支持中文输入法，组合态 Enter／ArrowDown 不触发选择或焦点移动，选择区中的组合态 Esc 不触发收起或关闭。ArrowDown 可进入已显示的首个可选结果，Tab／Shift+Tab 在窗口控件间循环并跳过禁用项。选择区内按 Esc 收起并返回展开按钮，再按 Esc 关闭添加窗口并恢复入口焦点；选中后收起选择区，焦点转到名称输入框，便于修改。

收藏夹读取复用扩展已有的 `bookmarks` 权限，不增加权限或联网搜索服务。加载、空收藏、无匹配与结果数使用状态提示，读取错误使用警报提示；保存或图标处理期间选择器控件禁用。

## 主题与响应式

选择器仅在新增网站窗口中出现，内嵌于名称字段上方。沿用 Lumno 的字体、圆角、按钮、输入框及浅色／深色主题；入口和结果按钮使用 2px 可见焦点轮廓。最后修正仅在收藏夹选择区覆盖占位文字：浅色 `#475569`、深色 `#b8c6d9`，已有复核确认默认与聚焦背景上的对比度均超过 4.5:1。

窗口宽度为 `min(420px, 100%)`，沿用安全区边距、动态视口高度约束和纵向滚动。结果区独立滚动，高度上限为 `min(220px, 30dvh)`；长标题、路径和网址单行省略，窄屏仍保留添加表单。仅在非 overlay 模式下，结果列表使用原生细滚动条与稳定槽位；规则限定于结果列表，overlay 模式沿用现有机制。减少动态效果偏好沿用原窗口实现。

## Direction contract

THESIS: Select existing bookmarks instead of retyping their URLs.
OWN-WORLD: Preserve Lumno's dialog, tokens, themes, groups and icon controls.
STORY: Add site; expand bookmark choices; search; select; optionally edit; save.
FIRST VIEWPORT: Inline chooser above the name field in the original 420px modal; bounded result scrolling.
FORM: Narrow Operate extension of the incumbent surface; no new identity or comp.
FINISH: Verify desktop, dark, mobile, keyboard, persistence and read-only bookmark access; finish review and scope-bound documentation.
