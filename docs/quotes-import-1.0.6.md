# 1.0.6 每行一句的自定义句库

在“外观 → 每日名句 → 自定义”上传 `.txt`、`.md` 或 `.markdown` 文件。

每个非空正文行独立作为一句，不需要空行分隔，不会把相邻行合并。空行跳过，重复行保留；兼容 Windows CRLF、LF、CR 换行及 UTF-8 BOM。TXT 保留原文，MD 去掉列表、引用等简单格式，并继续忽略标题、分隔线及围栏代码块。作者如需显示，请与句子写在同一行。

```text
千里之行，始于足下。——老子
保持好奇，持续学习。
今天也向前迈出一步。
```

上面的文件导入后得到三句。文件最多 1 MB，最多 1,000 句，每句最多 500 字符。内容仅保存在本机；无效文件或保存失败不覆盖旧句库。

已保存的旧句库保持不变。如旧文件的多行曾被合并，请重新导入，以应用“每行一句”的新规则。1.0.5 文档中的按段落导入规则仅对应旧版本。
